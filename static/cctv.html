真实监控视频 · 固定摄像机验收

原 Excel 场所模型优先：同一场所绑定多路固定摄像机，真实视频帧与公开标注分开展示

综合工作台视频运行统计分析合成业务规则摄像机/场所管理旧动画场景实验
此页使用爱丁堡大学 CAVIAR 的公开研究视频，不是模拟画面。 两台固定摄像机拍摄的是同一条商场走廊，因此应绑定同一个场所。CAVIAR 的 XML 是人工标注的人体框和各机位局部轨迹 ID； 此页不会将两个摄像机局部 ID 自动识别为同一自然人，也不能据此声称跨场所身份匹配或人脸识别成功。

素材：EC Funded CAVIAR project / IST 2001 37540；CC BY-SA。官方下载并保存在本地 data 目录，不进 Git 和演示源码包。需要联网下载。

① 绑定场所、导入两路真实监控

先选择一个 Excel 意义上的业务场所。走廊和正向视角是两路摄像机，不是“场所A/场所B”。演示默认固定场所归属，无需动漫镜头分场景。

统一数据契约：Frigate真实目标事件与CAVIAR官方逐帧标注分开统计。单个摄像机的100帧同一轨迹只记作1条局部出现事件，两路摄像机同名轨迹仍然是两条不同证据；没有跨机位真实人物去重，也不进入P###人库或业务到访统计。

⑤ 实际视频解码与人员检测分开验收

第一条链路：从官方素材读取视频帧。第二条链路：CAVIAR 官方人体框帮助验证目标出现。第三条链路：我们自己的模型检测与跟踪必须单独评估。

目前项目已有 OpenCV 的人脸候选检测；监控分辨率仅384×288，可能检测到0张脸。这不等于没有人员！后续的人体检测必须单独实测。
